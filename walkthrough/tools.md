# Console, server info, pub/sub

- Console: type any command. ↑ and ↓ walk the history, Tab completes command names. FLUSHALL, FLUSHDB, KEYS, DEBUG and SHUTDOWN ask first.
- Server info: memory, hit rate, keyspace, all INFO sections, the slow log and connected clients. In a cluster, pick the node.
- Pub/Sub: subscribe to a channel or a pattern and watch messages arrive; publish a test message.
- Export / Import: keys matching a pattern to JSON and back, binary safe.
