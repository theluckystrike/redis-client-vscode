# Changelog

## 0.1.0

- First release: Redis client and Redis GUI for VS Code. Single node, cluster and sentinel; TLS with a CA file; ACL users. Works with Redis, Valkey and KeyDB.
- Key tree with SCAN in pages, folders by separator, filter by pattern and type.
- Editors for strings (text, JSON, hex), hashes, lists, sets, sorted sets, streams (with consumer groups and pending entries) and RedisJSON. Binary safe end to end.
- Console with history and Tab completion; a question before FLUSHALL, FLUSHDB, KEYS, DEBUG and SHUTDOWN.
- Server info (INFO, slow log, clients, cluster nodes), pub/sub, export and import to JSON, read-only switch per connection.
- Zovo Pro (3 free tries each): Memory Analysis and Bulk TTL / Delete by Pattern with a dry run.
